# Reloadstar privacy policy

Reloadstar keeps the refresh interval in Chrome's local extension storage. During a refresh session it holds the tab ID, timer, and a fingerprint of the selected site in session storage. This lets it stop refreshing when the tab leaves that site. Chrome clears this state when it restarts. Reloadstar does not save URLs or browsing history, collect telemetry, or send extension data to an external server.

When you invoke Reloadstar, Chrome grants it temporary access to check whether the tab is a webpage it can refresh. Reloadstar does not read page content. A reload makes the same request to the website as Chrome's Reload button.

The Settings links open GitHub when selected. GitHub handles visits and issue reports under its own privacy policy. Please omit sensitive information from reports. [Reloadstar issues](https://github.com/lchavess1024/Reloadstar/issues)
