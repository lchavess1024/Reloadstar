# Reloadstar privacy policy

Reloadstar keeps the refresh interval and the optional keep-awake preference in Chrome's local extension storage. It holds active tab IDs and timers in session storage and clears them when Chrome restarts. Reloadstar does not save URLs or browsing history, collect telemetry, or send extension data to an external server.

When you invoke Reloadstar, Chrome grants it temporary access to check whether the tab is a webpage it can refresh. Reloadstar does not read page content. A reload makes the same request to the website as Chrome's Reload button. The optional **Keep awake while refreshing** setting lets Chrome request that the operating system prevent idle sleep while a session is active.

The Settings links open GitHub when selected. GitHub handles visits and issue reports under its own privacy policy. Please omit sensitive information from reports. [Reloadstar issues](https://github.com/lchavess1024/Reloadstar/issues)
